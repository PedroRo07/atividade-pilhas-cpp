## Descrição: 
Este repositório contém uma coleção de programas desenvolvidos em **C++ (Padrão C++17)** focados no estudo prático e teórico da estrutura de dados **Pilha (Stack)**. O objetivo principal deste projeto é dominar a **alocação sequencial de memória**, controle de ponteiros/índices de topo, validações de *Overflow/Underflow*, lógica LIFO (*Last In, First Out*) e análise de complexidade temporal e espacial, **sem o uso dos contêineres prontos da STL** (como `<stack>`).
